# Image attribution

Article thumbnails in `images/articles/` are free stock photographs served via [Lorem Picsum](https://picsum.photos/) (photos from the [Unsplash](https://unsplash.com/) collection).

- License: free to use under the [Unsplash License](https://unsplash.com/license)
- Purpose: internal demo publisher / ad layout testing
- Source API pattern: `https://picsum.photos/id/{id}/960/540`

Images are stored locally so the static site does not depend on external hosts at runtime.
